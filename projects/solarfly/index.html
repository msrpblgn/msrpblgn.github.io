Project Solarfly

A turn-based RPG written in C for the Game Boy Advance, set on the inside of a hollow world.

A 3D model of a teal Game Boy Advance SP. Its screen plays: A pixel-art battle. The camera zooms onto Aksil, then the protagonist, then two enemies, each time showing HP, a luck clover and stat values, before returning to the command menu.

3D model · real footage on screen

The Select status view, recorded from the ROM (17 Oct 2026 build) in mGBA with button input only.

Built and working

  • Turn-based battles on a five-tile formation per side, with targeting, movement skills, interacting status conditions, per-move charges (SC) and optional LP costs.
  • One shared Speed turn order for both teams: a unit at least twice as fast as an opponent gets one extra action just before that opponent's turn.
  • A Select status view: the camera zooms onto any unit and shows its HP, statuses, luck, LP and current stats.
  • A three-slot skill carousel with element-coloured cards.
  • A 30-stage roguelike mode with reward cards, recruitable allies, two bosses and a battery-backed save.
  • A tile overworld with collision, and a look-up view (L+R) that tilts the small screen up to the strange world overhead.
  • A dialogue system with portraits and authored pacing, plus Tool Demos: a battle builder, a dialogue demo and an overworld test.

Not built yet

  • Connected story maps, NPCs, warps and followers.
  • Story progression and a story save.
  • Audio and music.
  • The Dunclain boss cutscene, Conall's Heroism ability, Reika as a recruit, and equipment rewards.

What you're seeing

What I made

  • Game design: the world, characters, battle rules and roguelike structure.
  • All engine and gameplay code: battle, scheduler, rendering, overworld, dialogue, save, tools and host tests.
  • Character sprites and battle backgrounds drawn in Aseprite.

Try it

  1. Download the ROM: project_solarfly_gba.gba (Build from 17 Oct 2026 — the same build as the footage on this page)
  2. Install mGBA (0.10 or newer) and open the file with File → Load ROM.
  3. Default keys: X = A, Z = B, arrows = D-pad, Enter = Start, Backspace = Select, A/S = L/R.
